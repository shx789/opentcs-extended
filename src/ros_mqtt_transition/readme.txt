使用文档

在终端上输入命令:roslaunch ros_mqtt_transition ros_mqtt_transition.launch 


K1 K2 K3设置巡航点，K4设置回充

K1、K2同时按下，如果为导航状态，就结束；如果为回充状态，就退出回充；如果为错误状态，就错误清除


修改config文件夹下的test.json。
K1代表按钮1，K2代表按钮2，K3代表按钮3，K4代表按钮4

id			启动哪个巡航点，从0开始。
circulates		巡航点循环控制，1为循环，0为不循环。(循环表示到了最后一个点，以后又会前往第一个点；随机模式下设置id不生效)
dir
time			巡航到点停顿时间。
path_mode		1为轨道模式，0为正常模式，轨道模式全局路径将从轨道上规划。
path_stop_time 		轨道模式下的停车等待时间，0为无限等待，其它为等待多少秒，到达等待时间障碍物还在则报错。
run_speed		运行速度，范围是100-800。


K4是设置回充
time		回充容错次数，为整形，一般设为2-5次。
path_mode	1为轨道模式，0为正常模式，轨道模式全局路径将从轨道上规划。
run_speed	运行速度，范围时0.1-0.8m/s。

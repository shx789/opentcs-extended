# openTCS RCS 集成样例工作总结（2026-04-14）

---

## 2. 今日完成内容

### 2.1 openTCS HTTP 客户端落地

- 新增 `HttpOpenTcsOrderClient`
  - 调用 `POST /v1/transportOrders/{orderName}`
  - 支持请求超时
  - 支持 5xx/429 重试（指数退避）
  - 支持 Bearer Token
- `RcsIntegrationApplication` 支持按配置自动切换客户端：
  - 未配置 `rcs.openTcs.baseUrl` -> `InMemoryOpenTcsOrderClient`
  - 配置了 `rcs.openTcs.baseUrl` -> `HttpOpenTcsOrderClient`

---

### 2.2 CallbackSender 生产化样例

- 新增 `HttpCallbackSender`
  - 支持绝对/相对回调地址（相对地址依赖 `rcs.callback.baseUrl`）
  - 支持超时、Bearer Token
  - 支持 HMAC-SHA256 签名
  - 签名头：
    - `X-Callback-Timestamp`
    - `X-Callback-Signature`
  - 签名内容：`timestamp + "." + payloadJson`
- 新增 openTCS 事件接收接口：
  - `POST /api/v1/opentcs/events/transport-orders`
  - 流程：解析 -> 映射 -> 入 Outbox -> 触发发送

---

### 2.3 SSE 长连接消费器落地

- 新增 `OpenTcsSseTransportOrderSubscriber`
  - 连接 openTCS `SSE /events/transportOrders`
  - 自动重连（指数退避）
  - 断点续传（`Last-Event-ID`）
  - 支持 `X-Api-Access-Key` 和 Bearer Token
- `RcsIntegrationApplication` 已接入后台生命周期：
  - 启动后按配置开启 SSE 订阅
  - 进程退出时停止订阅线程

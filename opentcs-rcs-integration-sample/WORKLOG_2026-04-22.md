## 2. 今日实现

### 2.1 任务状态事件投影（从被动查询改为事件驱动）

1. `OpenTcsSseEventConsumer` 新增任务投影：
   - 基于 `mission_no` 关联 `TaskStore`。
   - 事件映射：
     - `ARRIVED_FROM/ARRIVED_TO/PICKED` -> `IN_PROGRESS`
     - `DROPPED` -> `INBOUND: WAIT_PLC` / `OUTBOUND: DONE`
     - `FAILED` -> `FAILED`
2. 新增 `WcsTaskStatusTransitions`，统一状态机转移校验，避免服务层和事件层规则分叉。

### 2.2 WCS -> WMS 结果回传（S1-T5）

1. 新增 DTO：
   - `api/dto/WmsTaskResultCallbackReq`
2. 新增服务：
   - `api/wcs/WmsTaskResultService`
   - 仅在配置 `rcs.wms.baseUrl`（或 `RCS_WMS_BASE_URL`）时启用回传。
   - 回传端点：
     - 入库：`{baseUrl}/api/v1/wms/inbound-results`
     - 出库：`{baseUrl}/api/v1/wms/outbound-results`
   - 幂等键：`biz_task_no + "|" + result_type`
3. `OpenTcsSseEventConsumer` 在任务进入终态（`DONE/FAILED/CANCELED`）时入 outbox，复用现有 retry。

### 2.3 Demo 与脚本

1. demo 新增结果接收入口：
   - `POST /demo/wms/inbound-results`
   - `POST /demo/wms/outbound-results`
2. `scripts/run-rcs-wcs-e2e.ps1` 更新：
   - 覆盖“出库任务接口链路”：
     - `POST /api/v1/wcs/outbound/tasks`
     - 注入 `FINISHED` 事件
     - `GET /api/v1/wcs/tasks/{biz_task_no}` 断言 `DONE`
     - 校验 mission callback (`DROPPED`) + WMS result callback (`DONE`)
   - 启动时自动检测端口占用，若冲突则切换空闲端口。
   - 启动 sample 时自动注入 `-Drcs.wms.baseUrl=http://127.0.0.1:{rcsPort}` 便于本地回环验收。
